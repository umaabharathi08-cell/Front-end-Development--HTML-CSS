🌸 Perfumy – Simple Perfume Website

📌 Project Overview
        Perfumy is a simple perfume website created using **HTML and CSS**. The project is designed as a beginner-level web development project to practice basic HTML structure and CSS styling.
        The website contains a navigation header, search bar, perfume product cards, product descriptions, and a contact section.

🛠️ Technologies Used
       HTML
       CSS

✨ Features

    🏠 Simple navigation bar
    🔍 Search bar
    🌸 Perfume product cards
    💰 Product price display
    📝 Product descriptions
    📞 Contact information section
    🎨 Basic hover effects
    📱 Simple and clean webpage layout

 📂 Project Structure

```text
Perfumy/
│
├── perfume.html
├── style.css
└── README.md
```

 🖥️ Website Sections

 1. Header
    The header contains the website name **Perfumy** and navigation items such as:
    * Home
    * Contact
    * About Us
    * Address

 2. Search Bar
    A simple search input is provided for searching perfumes.

 3. Products
   The website displays different perfume products with their prices, images, and descriptions.
   Example products include:

     * Cost – ₹200
     * Cost – ₹300
     * Cost – ₹400

 4. Contact Section
    The website includes contact details such as a phone number and email address.

 🎯 Objective
     The main objective of this project is to understand and practice:
         * HTML page structure
         * CSS styling
         * CSS classes
         * Navigation elements
         * Product card design
         * Hover effects
         * Basic webpage layout

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Make sure `perfume.html` and `style.css` are in the same folder.
4. Open `perfume.html` in any web browser.
5. The Perfumy website will be displayed.

📸 Project Preview
     The website provides a simple perfume-shopping-style interface with a header, search bar, product section, and contact details.
